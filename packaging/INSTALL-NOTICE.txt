케셰브 0.1.0 (검증 중인 버전) 설치 안내

케셰브는 이 PC에서만 열리는 보안 Agent 화면입니다. 설치하면 아래가 들어갑니다.
  - 설치 위치: %LOCALAPPDATA%\Programs\Keshev (이 사용자 계정 전용, 관리자 권한 필요 없음)
  - 앱 파일, Node.js 24.19.0(Windows x64 공식 배포본, LICENSE 포함)
  - 시작 메뉴: 「케셰브 시작」「케셰브 종료」, 바탕화면 바로가기(선택)

꼭 알아 둘 것
  1. 이 버전은 검증 중입니다. 실제 회사 시스템(SDP), 계정 연결, 앱 안 AI, 조치 실행,
     취약점 조회(OSV) 연결은 이 설치본으로 아직 확인하지 않았습니다(미확인).
  2. 기본 실행은 실제 시스템에 연결되지 않은 상태입니다. 화면에 「연결 없음」이 보이는 것이 정상입니다.
     「연결 없음」은 0건이나 안전하다는 뜻이 아닙니다.
  3. 서버는 이 PC의 127.0.0.1:5189 에서만 열립니다. 다른 PC에서는 접속할 수 없습니다.
  4. 설치본에는 토큰·비밀번호·API 키, 계정 연결·SDP 설정 파일, .env 가 들어 있지 않습니다.
  5. 코드 서명을 하지 않았습니다. 설치 파일을 열 때 Windows SmartScreen 경고
     ("Windows의 PC 보호")가 나올 수 있습니다. 직접 만든 설치 파일인지 확인한 뒤에만
     「추가 정보」→「실행」을 누르세요.
  6. 실행기는 PowerShell 을 이번 실행에만 -ExecutionPolicy Bypass 로 엽니다(PC 설정은 바꾸지 않음).
     회사 정책으로 스크립트 실행이 막힌 PC에서는 켜지지 않을 수 있습니다.

켜기·끄기
  - 「케셰브 시작」: 서버를 뒤에서 켜고 http://127.0.0.1:5189/ 를 브라우저로 엽니다.
    이미 켜져 있으면 화면만 엽니다.
  - 「케셰브 종료」: 이 설치 폴더의 node.exe 로 실행된 케셰브만 끕니다.

제거
  - Windows 설정 > 앱 > 설치된 앱 > 케셰브 > 제거
  - 제거 전에 실행 중인 케셰브를 끄고, 설치한 파일과 바로가기만 지웁니다.
    설치 폴더 밖의 사용자 파일은 지우지 않습니다.
