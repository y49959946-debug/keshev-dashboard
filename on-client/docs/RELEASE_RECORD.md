이 문서는 22단계 학생 작성 문서입니다. 아래 네 종류의 근거를 구분해 적습니다.

| 표기 | 뜻 |
|---|---|
| **실제 실행(학생 진술)** | 학생이 자기 PC에서 직접 명령을 실행하고 화면·출력을 확인한 결과. 서버가 대신 실행한 것이 아닙니다. |

| **원문 확인** | 저장소 원문(코드·문서)을 읽고 확인한 내용. 실행 성공 증명이 아닙니다. |

## 4. 이동 가능한 구성

| 항목 | 내용 | 근거 |
|---|---|---|
| 필요한 파일 | 저장소 전체(`on-client/` 아래). 외부 패키지 설치 없음 | 원문 확인 |
| 설치 절차 | Node.js 22~24(기준 24.19.0)와 Git만 설치 → `git clone` → `on-client`에서 실행 도구 실행 | 2장 재현 |
| 설정 예시 | `on-client/.env.example`: 비밀 없는 설정 견본(포트, 어댑터 경로, AI 모델 이름, 조회 대상은 빈 값). 실행 도구가 자동으로 읽지 않으며, 기본 실행은 설정 없이 동작 | 원문 확인 |
| 절대경로 의존 | 실행 코드는 절대경로에 의존하지 않습니다. 실행 도구는 자기 위치(`tools`의 상위)를 앱 폴더로 씁니다. `docs/STUDENT_RUNBOOK.md`의 `C:\Users\Administrator\…` 경로는 작성자 PC의 예시이며, 2장처럼 다른 폴더(`C:\KeshevRepro`)에서도 실행됐습니다. | 원문 확인, 실제 실행 |
| 비밀값 | 저장소에 열쇠·토큰·비밀번호·설정 파일 내용이 없습니다. 계정 연결·SDP 설정 파일은 운영자가 발급하며 프로젝트 밖에 두고 실행 옵션으로 경로만 넘깁니다. | 원문 확인 |

| 범위 | 상태 |
|---|---|
| 기본 실행(연결 없음), 종료·재실행 | 실제 실행으로 확인 |

| 실제 SDP 연결(`-SdpHostConfig`): 본인·기기·세션·업무 앱 판정·보안 기록 | **미해결**: 설정 파일을 받지 않음 |
| 계정 연결·AI 앱 승인(`-NativeHostConfig`), 실제 AI 점검·사건 설명 | **미해결**: `NATIVE_HOST_DISABLED` 확인. 설정 파일·앱 권한이 운영 측에서 준비되지 않음 |
| 보안 조치 실제 집행과 결과 재조회(19단계) | **미해결**: 실제 처리 연결이 준비되지 않음. 시험 집행을 하지 않음 |
| OSV 실제 조회(20단계) | **미해결**: 조회 대상·허용 목록 미준비(`not_configured`/`not_checked`가 나오는 상태) |
| `-Port`, `-Background`, `-WaitSeconds` 옵션 | 미확인 |
| Windows 외 운영체제, Chrome 외 브라우저 | 미확인(지원한다고 적지 않음) |

## 7. 시연·진술·원문 확인·실제 실행의 구분

- 2장의 재현 결과는 학생이 직접 실행하고 진술한 기록입니다.
- 3장의 ALEPH 판정은 원문 검토이며, 실행 성공 증명이 아닙니다.
- 예제(demo)로 본 결과는 실제 연결 성공으로 적지 않았습니다.
- 모의 데이터 점검 결과는 실제 연결 성공으로 적지 않았습니다.
- 이 문서는 확인하지 않은 동작을 확인했다고 적지 않습니다. 확인하지 않은 동작은 5장에 미확인·미해결로 남겼습니다.
